# 像素农场 · Pixel Farm

一个用原生 JavaScript + Canvas 2D 写的像素风农场经营游戏。无框架、无依赖、无构建步骤，打开网页就能玩。

- 游戏版本：`v0.1`
- 技术栈：HTML / CSS / 原生 JS（ES Modules）
- 渲染：Canvas 2D，逻辑分辨率 960 × 540，固定 60 FPS 步长
- 存档：浏览器 `localStorage`，3 个存档槽

## 功能

- **种植**：锄地、播种、浇水、施肥、收获，作物按季节生长，使用程序化像素美术按生长天数逐帧变化
- **作物美术**：完整移植 anim 图鉴的 50 种作物，全部可种植；种子按季节上架，生长与再收间隔沿用 demo 数据
- **农场经营**：金币、体力、背包 / 快捷栏、工具升级、水壶扩容
- **开局**：参考官方开局直接给齐六件工具（锄头 / 水壶 / 斧头 / 镐 / 镰刀 / 鱼竿）+ 四季种子
- **小镇**：杂货店、柜台交易、建筑与道路、室内外切换
- **NPC**：34 位 demo 村民 + 12 位特殊 NPC（博物馆 / 公会 / Joja / 岛屿 / 神秘）+ 3 位店主，全部使用 anim 像素行走与 64×64 头像；含真实作息、对话、送礼、好感、生日、来访农场、店主营业时间
- **建造**：鸡舍、牛棚、加工台、洒水器、道路等，支持放置与拆除；第 32 轮新增温室 / 筒仓 / 水井 / 磨坊 / 棚屋 / 图腾等 anim 建筑，以及社区中心、灶台与衣柜
- **换装**：建造衣柜后按 `E` 试穿 90 顶帽子 / 64 件上衣 / 16 件下装，搭配会保存并实时显示在农夫身上
- **工匠品**：28 种加工品接入物品表与加工台（葡萄酒 / 果汁 / 啤酒 / 奶酪 / 蛋黄酱 / 布 / 油 / 鱼籽酱等），配方自动保证利润率
- **料理**：81 道菜接入烹饪；建造灶台后按 `E` 打开独立烹饪面板，食谱按 80 道菜筛选
- **动物**：鸡 / 鸭 / 牛 / 羊 / 猪 / 兔 6 种，买动物、喂食、摸头、收集产品；使用 anim 动画（站立 / 走路 / 睡觉）
- **宠物**：15 种猫 / 狗 / 乌龟 / 马 / 铱星宠物，在农舍附近自由走动；按 `E` 抚摸，宠物碗可切换品种
- **钓鱼与采集**：季节鱼种、野花 / 蘑菇 / 浆果
- **鱼类**：钓鱼池扩展到 77 种（原有 8 种 + anim 图鉴），季节 / 时段 / 天气限制，图鉴使用 40×32 像素鱼图标
- **砍树与拾取**：树要砍 3 下，先摇晃再倒下；木材随机散落，走近自动吸附进背包
- **树木**：移植 anim 图鉴的 10 种野生树 + 8 种果树，按坐标分树种、按季节换叶；果树结果后按 `E` 采摘，3 天后再结果
- **采集动画**：石头敲两下碎裂、野花割倒淡出、锄地扬土、浇水水花与涟漪、收获碎叶
- **目标系统**：每日委托、节日、日历、32 个成就（anim 像素徽章）、农场评级、5 星终局结算
- **收集包**：30 个社区中心收集包；建造社区中心后按 `E` 打开，逐件交付，集满自动领金币
- **图鉴**：348 个条目（77 鱼 / 53 矿物 / 50 作物 / 6 动物 / 49 怪物 / 110 装备 / 3 采集物），全部使用像素图标，作物 / 动物 / 怪物 / 装备在首次收获 / 购买 / 击杀 / 拾取时解锁
- **装备**：110 件装备（62 武器 / 30 戒指 / 18 靴子）进入物品表；武器在矿井里按 dmg / crit 生效，怪物有概率掉落装备
- **收藏品**：室内 152 件（96 家具 / 32 墙纸 / 24 地板）、资源 100 种、动物产品 24 种、杂项 44 项全部进入物品表与商店，并使用像素图标
- **装修**：快捷栏选中家具后按 `H` 进入装修模式，左键摆放 / 右键拆回背包；建造「装修样板」后可预览并应用 32 种墙纸 / 24 种地板，选择写入存档
- **农舍室内**：屋前按 `E` 进入，WASD 走动，床边按 `E` 睡觉，走到门口按 `E` / `Esc` 出去；室内 `H` 摆放家具、灶台可直接烹饪，墙纸与地板使用装修样板的选择
- **背包图标**：背包 / 快捷栏 / 木箱 / 商店 / 收集包 / 加工与烹饪列表 / 拖动手持统一使用 anim 像素物品图标
- **HUD 图标**：金币 / 天气 / 明日预报 / 日历 / 体力，以及系统菜单 / 背包 / 商店页签改用 anim UI 像素图标
- **矿井与战斗**：按 `J` 进入矿井，打碎矿石、击杀怪物、掉落石材 / 木炭 / 金币，逐层下探
- **矿物**：53 种矿物（宝石 / 采集 / 晶洞），敲石头有概率掉落，捡到自动进图鉴，可出售
- **玩家动画**：游戏本体使用程序化农夫精灵，移动 / 奔跑 / 锄地 / 浇水 / 砍树 / 挖矿 / 钓鱼 / 吃东西都有独立动作
- **氛围**：昼夜光照、季节变化、天气（晴 / 雨 / 雪）、音效与静音

## 运行

项目使用 ES Modules，**不能直接双击 `index.html`**（`file://` 会被浏览器 CORS 拦截）。需要本地 HTTP 服务：

```bash
node serve.js
# 打开 http://127.0.0.1:8123/index.html
```

`serve.js` 是零依赖的 Node 静态服务器，并发送 `no-store` 缓存头，改完 JS 刷新即可看到最新模块。也可以用任意静态服务器：

```bash
python -m http.server 8123 --bind 127.0.0.1
```

## 操作

| 按键 / 鼠标 | 作用 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| `Shift` + 移动 | 奔跑（消耗体力） |
| `E` | 上下文交互：对话、睡觉、交易、开箱、加工、采集、委托板、动物 |
| 鼠标左键 | 使用当前手持物品 / 工具；**按住可连续使用**（连续砍树、锄地、浇水）；钓鱼时拉杆 |
| 鼠标右键 | 水壶补水；手持食物时吃一份；钓鱼时收竿 |

| `Tab` / `I` | 打开 / 关闭背包 |
| `B` | 进出建造模式 |
| 建造模式滚轮 | 切换配方 |
| 建造模式左键 / 右键 | 放置 / 拆除 |

| `J` | 进入 / 离开矿井（WASD 移动，空格挥剑，走到梯子下一层） |
| `Esc` | 关闭当前面板；没有面板时打开系统菜单 |

```text

│   ├── render/         # 瓦片、建筑、作物、实体绘制
│   ├── systems/        # 种植、背包、商店、时间、天气、动物、委托等
│   ├── ui/             # 背包、商店、菜单等 DOM 面板
```

**改功能时只需要找对应模块**，完整文件地图见 [js/README.md](js/README.md)。

## 开发说明

- `js/main.js` 的 import 顺序等于原单文件脚本的执行顺序，新增模块时放在它依赖的模块之后。
- 当前采用过渡期的模块桥：顶层 `const` / `function` / `class` 会同时挂到 `window` 并 `export`；可变共享状态用 `window.X = ...`。新增符号时记得同步更新文件末尾的 `Object.assign(window, {...})` 和 `export { ... }`。
- 没有构建步骤，改完 JS 刷新页面即可。
- 调试：在控制台执行 `CONFIG.DEBUG_HOOK = true` 后刷新，可得到 `window.__game`，包含游戏内部函数与状态。
