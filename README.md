# 像素农场 · Pixel Farm

一个用原生 JavaScript + Canvas 2D 写的像素风农场经营游戏。无框架、无依赖、无构建步骤，打开网页就能玩。

- 游戏版本：`v0.1`
- 技术栈：HTML / CSS / 原生 JS（ES Modules）
- 渲染：Canvas 2D，逻辑分辨率 960 × 540，固定 60 FPS 步长
- 存档：浏览器 `localStorage`，3 个存档槽

## 功能

- **种植**：锄地、播种、浇水、施肥、收获，作物按季节生长
- **农场经营**：金币、体力、背包 / 快捷栏、工具升级、水壶扩容
- **小镇**：杂货店、柜台交易、建筑与道路、室内外切换
- **NPC**：真实作息与站位、对话、送礼、好感、生日、来访农场、店主营业时间
- **建造**：鸡舍、牛棚、加工台、洒水器、道路等，支持放置与拆除
- **动物**：买动物、喂食、摸头、收集产品
- **钓鱼与采集**：季节鱼种、野花 / 蘑菇 / 浆果
- **目标系统**：每日委托、节日、日历、成就墙、农场评级、5 星终局结算
- **氛围**：昼夜光照、季节变化、天气（晴 / 雨 / 雪）、音效与静音

## 运行

项目使用 ES Modules，**不能直接双击 `index.html`**（`file://` 会被浏览器 CORS 拦截）。需要本地 HTTP 服务：

```bash
node serve.js
# 打开 http://127.0.0.1:8123/index.html
```

`serve.js` 是零依赖的 Node 静态服务器。也可以用任意静态服务器：

```bash
python -m http.server 8123 --bind 127.0.0.1
```

## 动画测试 Demo

`anim-demo.html` 是独立的像素动画测试页，不参与游戏主循环：

```bash
node serve.js
# 打开 http://127.0.0.1:8123/anim-demo.html
```

- **农夫**：12 个动作（站立 / 走路 / 奔跑 / 锄地 / 浇水 / 砍树 / 挖矿 / 割草 / 收获 / 钓鱼 / 睡觉 / 受击）× 4 个朝向
- **植物**：星露谷 1.6 全部 50 种作物，逐日生长，一帧 = 一天（如 6 天成熟就是 6 帧）
- **换季测试**：通用枯萎帧；多季作物（上古水果 / 咖啡豆 / 玉米 / 向日葵 / 小麦）在对应换季存活，其余作物会枯萎
- **动物**：鸡 / 鸭 / 牛 / 羊 / 猪 / 兔，每只 4 个动作（站立 / 走路 / 进食 / 睡觉），支持左右朝向
- 支持播放暂停、逐帧、速度、整数倍缩放、网格、背景、PNG 导出
- 每个分类都有“全部动作 / 阶段 × 方向或物种”的自动循环画廊
- 动画模块位于 `js/anim/`，无游戏全局依赖，可直接复用到游戏里
- 作物数据按星露谷 1.6.15 作物表整理（共 50 项，含野种、纤维、齐瓜等特殊作物）

## 操作

| 按键 / 鼠标 | 作用 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| `Shift` + 移动 | 奔跑（消耗体力） |
| `E` | 上下文交互：对话、睡觉、交易、开箱、加工、采集、委托板、动物 |
| 鼠标左键 | 使用当前手持物品 / 工具；钓鱼时拉杆 |
| 鼠标右键 | 水壶补水；手持食物时吃一份；钓鱼时收竿 |
| `1` ~ `8` | 选择快捷栏 |
| `Tab` / `I` | 打开 / 关闭背包 |
| `B` | 进出建造模式 |
| 建造模式滚轮 | 切换配方 |
| 建造模式左键 / 右键 | 放置 / 拆除 |
| `G` | 农场评级 / 雇工 |
| `Esc` | 关闭当前面板；没有面板时打开系统菜单 |
| `P` | 暂停菜单 |
| `M` | 静音 / 取消静音 |
| 点击左上日期 | 打开日历 |
| 点击右上评分 | 打开农场评级 |
| 点击右上小地图 | 打开全屏地图 |

## 项目结构

```text
.
├── index.html          # 页面骨架、样式、DOM 面板
├── serve.js            # 零依赖本地静态服务器
├── js/
│   ├── main.js         # 唯一入口：按顺序 import 所有模块
│   ├── config.js       # 全部可调参数与游戏数据
│   ├── world/          # 地图生成、建筑定义
│   ├── render/         # 瓦片、建筑、作物、实体绘制
│   ├── systems/        # 种植、背包、商店、时间、天气、动物、委托等
│   ├── ui/             # 背包、商店、菜单等 DOM 面板
│   ├── npc/            # NPC 日程、移动、对话、送礼、好感、存档
│   ├── player.js       # 玩家精灵
│   ├── save.js         # 存档序列化
│   ├── main-loop.js    # 固定步长主循环
│   ├── boot.js         # 启动初始化
│   └── README.md       # 模块地图与开发约定
└── legacy_pixel_farm.html  # 早期单文件原型（历史参考）
```

**改功能时只需要找对应模块**，完整文件地图见 [js/README.md](js/README.md)。

## 开发说明

- `js/main.js` 的 import 顺序等于原单文件脚本的执行顺序，新增模块时放在它依赖的模块之后。
- 当前采用过渡期的模块桥：顶层 `const` / `function` / `class` 会同时挂到 `window` 并 `export`；可变共享状态用 `window.X = ...`。新增符号时记得同步更新文件末尾的 `Object.assign(window, {...})` 和 `export { ... }`。
- 没有构建步骤，改完 JS 刷新页面即可。
- 调试：在控制台执行 `CONFIG.DEBUG_HOOK = true` 后刷新，可得到 `window.__game`，包含游戏内部函数与状态。
