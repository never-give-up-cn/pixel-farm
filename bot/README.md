# 自动农场机器人

一个**看得见、正常速度**的自动游玩脚本：机器人自己走到地块旁边、开垦、播种、浇水、收获、去镇上卖货买种子，然后回家睡觉。

每天结束时把资产变化当作奖励，对 5 个策略参数做爬山式进化，并保存在浏览器 `localStorage`（键名 `farm_bot_v1`）。用 `npm run bot` 启动时还会同步到 `bot/learned-policy.json`，所以关掉窗口后下次会接着上次的学习进度继续迭代。它**不写游戏存档**，也不会覆盖已有存档槽。

## 运行

```bash
npm install
npm run bot
```

会自动打开 Chrome 并访问：

```text
http://127.0.0.1:8123/index.html?bot=1
```

也可以先 `node serve.js`，再手动在 Chrome 打开上面的地址。

## 机器人做什么

- 按正常游戏速度走路和使用工具，操作经过游戏动画与命中帧结算。
- 每天：收获 → 浇水 → 开垦 → 播种 → 从农场南口走到鹈鹕镇，去商店卖货 + 买明天的种子 → 回农场睡觉。
- 用第一个**空存档编号**开局；本次会话关闭自动存档，关闭页面后不留下机器人存档。
- 所有存档位都有存档时会停下来提示，不会覆盖任何进度。

## 在学什么

| 参数 | 含义 |
|---|---|
| `targetTiles` | 今天经营多少块地（12–48） |
| `cropMode` | 选作物偏好：利润/天、最快成熟、单株最贵 |
| `canUpgrade` | 有钱时要不要升级水壶 |
| `staminaReserve` | 留多少体力收工 |
| `seedSpend` | 每天最多把多少比例的金币拿来买种子 |

每天结算的奖励 = 当日资产变化：

```text
金币 + 背包可卖物价值 + 站立作物价值 + 已开垦地价值
```

如果今天比历史最佳更高，就保留这套策略；否则回到最佳策略，再随机改动一个参数继续试。右下角面板会显示当日收益、最佳收益、历史曲线和最近动作。

## 面板按钮

- **暂停 / 继续**：暂停机器人决策（不会暂停游戏时间）。
- **重置学习**：清空 `farm_bot_v1`，重新从默认策略开始；`bot/learned-policy.json` 会在几秒内被新的学习进度覆盖。
- **停止**：停止机器人，玩家可以接管当前这局。

## 注意

- 这是可视化演示，不适合批量刷数据；机器人通常下午收工，正常速度下一天约 3–5 分钟。
- 机器人只做农场循环（第一版），不下矿、不钓鱼、不参加节日。
