# NPC 居住与工作

> 这是游戏内 49 位 NPC 的住宅、职业、工作地点与常见出现位置。
> 资料按《星露谷物语》的住户关系、职业和常去地点整理，再映射到本作的城镇与周边地图。
> 住宅仍在农场/小镇的四排住宅区；部分居民白天会跨地图去山地、森林、海滩上班。

## 城镇布局

```text
地图：128 × 104
城镇带：38 ~ 96 行

第一排街：42 行，房子：43 ~ 52 行
第二排街：56 行，房子：57 ~ 66 行
第三排街：70 行，房子：71 ~ 80 行
第四排街：84 行，房子：85 ~ 94 行
南北主路：58 ~ 59 列，贯穿四排
```

- 每排 8 个住宅地块。
- 每栋房子都有门、床、桌子、灶台、箱子、货架、地毯，以及职业对应的工作家具（柜台 / 工作台 / 书桌 / 花摊）。
- 一栋房子可以住 1~4 人。
- 门口牌子会写「谁在家 / 谁在工作 / 谁出门了」，走近可看详细文字。

## 找人技巧

- **8:00–9:00**：大量居民在上街，适合一次性认人。
- **9:00–17:00**：多数人在工作地点，进对应房子 / 店铺找。
- **17:00–21:00**：下班居民在各自住宅附近的街上，镇子最热闹。
- **21:00 之后**：大部分人回家，部分夜班在酒馆 / 赌场。
- 门口牌子会写「N 人在家 / 正在工作 / 主人出去了」，不用盲目敲门。
