# 多地图说明

本作现在由 9 张独立地图组成，布局参考《星露谷物语》的区域拓扑，像素图全部由本项目程序化重绘，不直接使用原游戏素材。

## 世界拓扑

```text
                      采石场
                        ↑
                      山地
                        ↑
                       │
秘密森林 ←── 煤渣森林 ←──── 鹈鹕镇 ────→ 巴士站 ──(巴士)──→ 卡利科沙漠
                              │  ↑
                              ↓  │
                             农场
                              │
                              ↓
                           鹈鹕海滩
```

- **农场**：独立地图，30×22 的主耕地、农舍、水塘、可砍伐的树林 / 矿石；南口去小镇，北口去山地。
- **鹈鹕镇**：独立地图，四排住宅、商店、广场、赌场、社区中心；北口回农场，西 / 东 / 南口去森林 / 巴士站 / 海滩。
- **山地**：北边，湖泊、罗宾木匠店、矿井、冒险家公会、莱纳斯的帐篷、采石场桥。
- **采石场**：山地东北，过桥进入；裸岩地、石路、小水潭、八条每日矿脉。
- **煤渣森林**：西边，河流、池塘、玛妮牧场、莉亚小屋、法师塔、秘密森林入口、旅行货车。
- **秘密森林**：森林西北角，通过大原木进入；中央池塘、六棵硬木树桩、古老雕像。
- **鹈鹕海滩**：南边，沙滩、海、栈桥、威利鱼店、艾利欧特小屋、潮池。
- **巴士站**：小镇东边，一条东西向公路和停靠的巴士；修好后坐车去沙漠。
- **卡利科沙漠**：巴士终点，沙地、绿洲、沙漠商人、骷髅洞穴入口。

## 各地图内容

### 农场

- 独立地图，30×22 的主耕地，农舍在西北角，水塘在西南 / 东北（按农场类型）。
- 可以开垦、建造、养动物、摆家具；树 / 石头只长在农场边缘，中央留作可耕地。
- **建筑占地**：鸡舍 2×2、牛棚 / 棚屋 / 鱼塘 3×2、温室 3×3 等大型建筑按整块占地放置，整块挡路、整块拆除；木箱 / 洒水器 / 加工设备等小物件仍占 1 格。农场比原来大，建造前先规划大建筑的位置。
- **农场类型**：开局可在标题界面选择标准 / 河流 / 森林 / 山顶四种农场，只改变农场空地内部的地形与植被密度；农舍、出生点和南北主路固定保留。
  - 标准：大片草地 + 小水塘，可耕地最多。
  - 河流：一条 2 格宽的河从农场东半部穿过，出生点高度有桥；河面可钓鱼。
  - 森林：农场边缘树木更多，清树后即可开垦。
  - 山顶：农场边缘散布矿石与一小片水塘，石材更多、平地更少。
- 北出口：山地。
- 南出口：鹈鹕镇。

### 鹈鹕镇

- 独立地图，四排住宅、商店、中央广场、赌场、社区中心；建筑按星露谷鹈鹕镇的感觉重新排布：北侧是杂货店 / 诊所 / 博物馆和中央广场，中排是住宅，南侧是酒馆 / 铁匠 / Joja / 公会 / 赌场。
- 可以交易、对话、送礼、进入住宅；不能开垦 / 建造 / 摆家具。
- **节日广场**：每季第 5 天，广场会装饰起来并摆出集市摊位；走到广场中央按 `E` 可玩当季小游戏，四季玩法与奖励不同。
- **赌场**：第一排住宅最东端，进屋可玩老虎机 / 轮盘、找齐先生接任务、用齐币兑换物资（需要俱乐部卡）。
- 北出口：农场。
- 西出口：煤渣森林。
- 东出口：巴士站。
- 南出口：鹈鹕海滩。

### 山地

- 大湖：可以钓鱼。
- 罗宾木匠店：山地西侧。
- 矿井：山地南侧偏左；入口按 `E` 下矿 / 打开电梯，也可以按 `J` 直接进入。每下 5 层解锁电梯直达层，最深纪录与矿工宝箱领取记录随存档保存。矿井按深度分岩石 / 冰霜 / 熔岩三层主题，配色和矿石池都会变化。
- 冒险家公会：山地南侧偏右。
- 莱纳斯的帐篷：湖北岸。
- 采石场桥：东侧，按 `E` 过桥进入采石场。
- 矿车：矿井入口旁；Joja 社区发展修好后，按 `E` 直达巴士站 / 采石场。
- 可以走路、钓鱼、看地标；不能开垦 / 建造。

### 采石场

- 从山地东北的采石场桥按 `E` 进入。
- 裸岩地、石路、小水潭；水潭可以钓鱼。
- 八条矿脉：岩石、铜矿脉、铁矿脉、金矿脉、煤矿脉。
- 每条矿脉每天可采一次：
  - 岩石 → 石头 ×3
  - 铜矿脉 → 铜矿石 ×2 + 石头 ×2
  - 铁矿脉 → 铁矿石 ×2 + 石头 ×2
  - 金矿脉 → 金矿石 ×1 + 石头 ×3
  - 煤矿脉 → 煤炭 ×2 + 石头 ×2
- 采过的矿脉当天变成碎石，第二天恢复；采集记录随存档保存。
- 矿车：南侧路边；Joja 社区发展修好后，按 `E` 直达山地矿井 / 巴士站。
- 南边出口回到山地。

### 煤渣森林

- 南北向河流与两座桥。
- 西北池塘：可以钓鱼。
- 玛妮牧场：森林东北，入口主路北侧。
- 莉亚小屋：森林东南。
- 法师塔：森林中部偏西。
- 秘密森林入口：西北角。
- 旅行货车：东岸、桥北侧，走近按 `E` 打开轮换商店。
  - 每 3 天换 4 件商品，价格 ×1.3。
  - 只买不卖，库存按季节天数轮换。
- 可以走路、钓鱼、看地标；不能开垦 / 建造。

### 秘密森林

- 从煤渣森林西北角的大原木按 `E` 进入。
- 中央池塘可以钓鱼，周围是密集树林和土路。
- 六棵硬木树桩：每个树桩每天可以砍一次，获得 **硬木 ×2**。
- 砍过的树桩当天会露出年轮，第二天恢复；砍伐记录随存档保存。
- 古老雕像：带着 **甜宝石浆果** 按 `E` 献上，永久获得 **体力上限 +10**（只能领一次）。
- 南边出口回到煤渣森林。

### 鹈鹕海滩

- 沙滩 + 海 + 木栈桥。
- 威利鱼店：沙滩东侧。
- 艾利欧特小屋：沙滩西侧。
- 潮池：沙滩中部。
- 可以在海里 / 栈桥钓鱼；不能开垦 / 建造。

### 巴士站

- 从小镇第一排街一路往东走到尽头进入。
- 一条东西向公路，路边停着黄色巴士。
- 巴士一开始抛锚：走到巴士旁按 `E` 询问价格，再按一次确认修理。
  - 普通玩家 **40000g**。
  - Joja 会员 **25000g**。
- 修好后在巴士旁按 `E`，在巴士站和卡利科沙漠之间往返。
- 矿车：巴士旁；Joja 社区发展修好后，按 `E` 直达山地矿井 / 采石场。
- 东侧公路出口回到小镇第一排街东端。
- 巴士修理状态随存档保存；新游戏需要重新修理。

### 卡利科沙漠

- 巴士终点，四周是岩石边界，没有步行出口，只能坐巴士回去。
- **沙漠商人**：北侧小土房，按 `E` 打开商店。
  - 价格 ×1.2，只买不卖。
  - 出售炸弹、楼梯、咖啡、钻石、铱矿石、金矿石、杨桃种子、甜宝石浆果种子、仙人掌果。
- **骷髅洞穴**：东侧岩壁洞口，按 `E` 进入。
  - 需要矿井最深纪录达到 **B40**，否则提示先找骷髅钥匙。
  - 进入后从 B1 开始，怪物生命 / 伤害更高，掉落更好。
- **绿洲**：沙漠中部的水池，可以钓鱼。
- 仙人掌、风化岩是装饰，不能开垦 / 建造。

## 当前限制

新地图目前是**探索地图**：

- 可以移动、钓鱼、查看地标、进入住宅。
- 暂不支持在新地图开垦、播种、建造、摆放家具。
- 罗宾一家、玛妮 / 谢恩、莉亚、法师、威利、艾利欧特、莱纳斯、马龙 / 吉尔会白天跨地图上班 / 活动。
- 这些居民晚上回新地图的住宅室内；镇上的旧宅仍在，但会显示主人外出。
- 后续可以继续给森林 / 山地 / 海滩补更多可进入的店铺和居民。
