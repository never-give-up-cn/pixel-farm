# 多地图说明

本作现在由 6 张独立地图组成，布局参考《星露谷物语》的区域拓扑，像素图全部由本项目程序化重绘，不直接使用原游戏素材。

## 世界拓扑

```text
                     采石场
                       ↑
                     山地
                      ↑
                      │
秘密森林 ←── 煤渣森林 ←──── 农场与小镇 ────→  （东侧暂无）
                      │
                      ↓
                   鹈鹕海滩
```

- **农场与小镇**：原来的 128×104 地图，包含农场、农舍、四排住宅、商店。
- **山地**：北边，湖泊、罗宾木匠店、矿井、冒险家公会、莱纳斯的帐篷、采石场桥。
- **采石场**：山地东北，过桥进入；裸岩地、石路、小水潭、八条每日矿脉。
- **煤渣森林**：西边，河流、池塘、玛妮牧场、莉亚小屋、法师塔、秘密森林入口、旅行货车。
- **秘密森林**：森林西北角，通过大原木进入；中央池塘、六棵硬木树桩、古老雕像。
- **鹈鹕海滩**：南边，沙滩、海、栈桥、威利鱼店、艾利欧特小屋、潮池。

## 各地图内容

### 农场与小镇

- 农场、农舍、田地、动物、宠物、29 栋住宅、商店、社区中心。
- 可以开垦、建造、养动物、摆家具、交易。
- 北出口：山地。
- 西出口：煤渣森林。
- 南出口：鹈鹕海滩。

### 山地

- 大湖：可以钓鱼。
- 罗宾木匠店：山地西侧。
- 矿井：山地南侧偏左；入口按 `E` 下矿 / 打开电梯，也可以按 `J` 直接进入。每下 5 层解锁电梯直达层，最深纪录随存档保存。
- 冒险家公会：山地南侧偏右。
- 莱纳斯的帐篷：湖北岸。
- 采石场桥：东侧，按 `E` 过桥进入采石场。
- 可以走路、钓鱼、看地标；不能开垦 / 建造。

### 采石场

- 从山地东北的采石场桥按 `E` 进入。
- 裸岩地、石路、小水潭；水潭可以钓鱼。
- 八条矿脉：岩石、铜矿脉、铁矿脉、金矿脉、煤矿脉。
- 每条矿脉每天可采一次：
  - 岩石 → 石头 ×3
  - 铜矿脉 → 铜矿石 ×2 + 石头 ×2
  - 铁矿脉 → 铁矿石 ×2 + 石头 ×2
  - 金矿脉 → 金矿石 ×1 + 石头 ×3
  - 煤矿脉 → 煤炭 ×2 + 石头 ×2
- 采过的矿脉当天变成碎石，第二天恢复；采集记录随存档保存。
- 南边出口回到山地。

### 煤渣森林

- 南北向河流与两座桥。
- 西北池塘：可以钓鱼。
- 玛妮牧场：森林东北，入口主路北侧。
- 莉亚小屋：森林东南。
- 法师塔：森林中部偏西。
- 秘密森林入口：西北角。
- 旅行货车：东岸、桥北侧，走近按 `E` 打开轮换商店。
  - 每 3 天换 4 件商品，价格 ×1.3。
  - 只买不卖，库存按季节天数轮换。
- 可以走路、钓鱼、看地标；不能开垦 / 建造。

### 秘密森林

- 从煤渣森林西北角的大原木按 `E` 进入。
- 中央池塘可以钓鱼，周围是密集树林和土路。
- 六棵硬木树桩：每个树桩每天可以砍一次，获得 **硬木 ×2**。
- 砍过的树桩当天会露出年轮，第二天恢复；砍伐记录随存档保存。
- 古老雕像：带着 **甜宝石浆果** 按 `E` 献上，永久获得 **体力上限 +10**（只能领一次）。
- 南边出口回到煤渣森林。

### 鹈鹕海滩

- 沙滩 + 海 + 木栈桥。
- 威利鱼店：沙滩东侧。
- 艾利欧特小屋：沙滩西侧。
- 潮池：沙滩中部。
- 可以在海里 / 栈桥钓鱼；不能开垦 / 建造。

室内有墙、地板、床、桌子、灶台、箱子、书架、地毯；走到门口回到外景。居民在家时会出现在室内。

- 床边按 `E`：睡觉
- 箱子旁按 `E`：储物
- 灶台旁按 `E`：烹饪（和自家灶台同一套面板）

山地 · 矿井入口按 `E` 可以直接进入矿井（也可以按 `J`）。

## 当前限制

新地图目前是**探索地图**：

- 可以移动、钓鱼、查看地标、进入住宅。
- 暂不支持在新地图开垦、播种、建造、摆放家具。
- 罗宾一家、玛妮 / 谢恩、莉亚、法师、威利、艾利欧特、莱纳斯、马龙 / 吉尔会白天跨地图上班 / 活动。
- 这些居民晚上回新地图的住宅室内；镇上的旧宅仍在，但会显示主人外出。
- 后续可以继续给森林 / 山地 / 海滩补更多可进入的店铺和居民。
