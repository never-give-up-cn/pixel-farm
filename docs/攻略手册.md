# 像素农场 · 攻略手册

> 面向已经会操作、想把日子过得更有效率的玩家。
> 第一次玩先看 [游玩指南](游玩指南.md)。

## 1. 核心循环

每天优先做这四件事：

```text
浇水 / 收获 → 镇上卖货 + 送礼 → 采集 / 钓鱼 / 下矿 → 睡觉
```

三条硬约束：

1. **体力 250**，浇水、开垦、砍树、挖矿、奔跑都吃体力。
2. **一季 28 天**，作物要算好成熟时间，别拖到换季。
3. **商店 10:00–19:00**，老板娘 12:00–13:00 午休。

## 2. 第一季（春 1–28 天）路线

### 第 1 天

- 在农舍附近开 20–30 块地。
- 先种防风草、土豆、胡萝卜，回本快。
- 想完成春季收集包，同时种：
  - 青豆 10 天成熟
  - 花椰菜 12 天成熟
  - 土豆 6 天成熟
  - 防风草 4 天成熟
- 下午去镇上对话、送礼，认识店主。
- 采集野花，留 5–10 朵当通用礼物。
- 睡前把水壶补满。

### 第 2–7 天

- 每天先浇水，再收获成熟作物。
- 防风草种下 4 天后收，土豆 6 天后收。
- 卖一部分作物，补种子；留一部分交收集包。
- 砍树攒木材，敲石头攒石材，为洒水器和鸡舍做准备。

### 第 5 天：播种祭

- 当天播种的作物，当晚多长 1 天（相当于提前 1 天成熟）。
- 把长周期作物留到这天播：花椰菜、青豆、南瓜等。

### 第 8–14 天

- 青豆种下 10 天后开始收，之后每 3 天再收一次。
- 花椰菜种下 12 天后成熟。
- 卖钱后优先造洒水器，减少每天的浇水体力。
- 攒鸡舍材料：木材 ×12。
- 每天给重点 NPC 送礼，优先冲「朋友」档。

### 第 15–21 天

- 造加工台，把葡萄 / 番茄 / 土豆 / 牛奶 / 鸡蛋做成工匠品。
- 有余力建鸡舍，买第一只鸡。
- 下矿 5–10 层，攒铜矿、铁矿、煤炭。
- 继续补春季收集包。

### 第 22–27 天

- 收完大部分作物。
- 补齐收集包，卖掉囤货。
- 准备夏季种子：夏南瓜、辣椒、啤酒花、甜瓜。
- 别在换季前 3 天种长周期作物。

### 第 28 天

- 收完所有当季作物。
- 没熟的作物会在换季时枯萎。
- 夏季第 1 天重新开垦 / 播种。

## 4. 体力规划

250 体力大约能支持：

| 一天的内容 | 消耗 |
|---|---:|
| 50 块地浇水 | 50 |
| 50 块地开垦 | 150 |
| 50 次收获 | 50 |
| **合计** | **250** |

也就是说，**第一天开 50 块地 + 浇水 + 收获刚好见底**，没有余力下矿。

更稳的日常：

| 内容 | 消耗 |
|---|---:|
| 30 块地浇水 | 30 |
| 30 次收获 | 30 |
| 少量开垦 / 砍树 | 30–60 |
| 奔跑 30 秒 | 30 |
| **剩余** | **100+** |

建议：

- 农田控制在「浇水 + 收获 + 开垦」不超过 180。
- 造洒水器后，浇水体力直接归零。
- 随身带 2–3 份料理，每份 +40。
- 不要在体力低于 50 时下矿或远行。
- 2:00 前回家睡觉，昏睡会让次日上限变 200。
- 每次工具 / 收获动作约 0.5–0.8 秒，体力在动作命中帧扣除；动作期间不能移动，连续操作会自动排队。

## 5. 赚钱路线

### 路线 A：作物 + 加工（最稳）

1. 春季青豆 / 草莓 / 土豆起手。
2. 夏季啤酒花 / 夏南瓜 / 辣椒。
3. 秋季葡萄 / 西兰花 / 茄子。
4. 造加工台，把原料变成工匠品。

高价值配方（原料 → 成品）：

| 配方 | 原料 | 售价 |
|---|---|---:|
| 淡啤酒 | 啤酒花 ×3 | **547** |
| 葡萄酒 | 葡萄 ×3 | **518** |
| 咖啡 | 咖啡豆 ×3 | **480** |
| 松露油 | 松露 ×1 | **1100** |
| 布 | 羊毛 ×1 | **700** |
| 果汁 | 番茄 ×3 | 250 |
| 腌菜 | 土豆 ×3 | 288 |
| 奶酪 | 牛奶 ×2 | 200 |
| 蛋黄酱 | 鸡蛋 ×1 | 190 |

优先把「单价高、产量大」的原料送进加工台，不要直接卖。

### 路线 B：动物

| 动物 | 价格 | 成熟 | 产物 | 加工后 |
|---|---:|---:|---|---:|
| 鸡 | 120 | 2 天 | 鸡蛋 | 蛋黄酱 190 |
| 牛 | 260 | 4 天 | 牛奶 | 奶酪 200 |
| 鸭 | 200 | 4 天 | 鸭蛋 | 鸭蛋黄酱 220 |
| 羊 | 800 | 3 天 | 羊毛 | 布 700 |
| 猪 | 1600 | 5 天 | 松露 | 松露油 1100 |
| 兔 | 400 | 6 天 | 兔脚 | — |

- 每天喂饲料（8 金）+ 摸头，好感才涨。
- 好感 50 以上稳定产出，越高越容易出优质产品。
- 鸡和牛回本最快；猪最贵但松露油最赚。

### 路线 C：钓鱼

- 鱼竿开局就有，0 成本。
- 稀有鱼绿区小，但单价高。
- 雨天 / 特定时段会出稀有鱼。
- 鱼可以交河鱼 / 湖鱼 / 海鱼 / 夜间鱼收集包。
- 钓到重复鱼就卖，第一条留图鉴。

### 路线 D：秘密森林硬木

- 从煤渣森林西北角的大原木按 `E` 进入秘密森林。
- 六棵硬木树桩每天各砍一次，共 **硬木 ×12 / 天**。
- 硬木是后期建筑、加工设备的关键材料，建议每天顺路收一遍。
- 中央池塘也能钓鱼，跑一趟可以同时补给。
- 深处有一座古老雕像：带一颗 **甜宝石浆果** 按 `E`，永久 **体力上限 +10**（一次）。甜宝石浆果秋季 24 天成熟，看到种子就囤一颗。

### 路线 E：下矿

- 矿石、宝石、煤炭都能卖。
- 怪物掉装备，装备也能卖。
- 深层收益高，但需要武器和料理。
- 前期只下 5–10 层，攒铜矿 / 铁矿 / 煤炭就回。

### 路线 F：采石场

- 山地东北的采石场桥按 `E` 过桥。
- 八条矿脉每天可采一轮，稳定拿到石头、铜 / 铁 / 金矿石和煤炭。
- 采石场是安全区，没有怪物；缺矿石又不想下矿时优先来这里。
- 小水潭也能钓鱼，顺路可以补图鉴。
- 每天建议路线：秘密森林砍硬木 → 采石场采矿石 → 回农场浇水。

### 路线 G：旅行货车淘货

- 煤渣森林东岸、桥北侧停着旅行货车，走近按 `E`。
- 每 3 天换 4 件商品，价格是普通商店的 **1.3 倍**。
- 只买不卖，适合补当天商店缺的材料。
- 值得留意的货：钻石、金 / 铁矿石、星之果实种子、甜宝石浆果种子。
- 顺路顺序：进煤渣森林 → 看货车 → 西北角进秘密森林砍硬木。
- 金币紧张时不要冲动：同样的矿石去采石场每天白拿，货车只在急需时买。

### 送礼

- 每人每天 1 次。
- 喜欢 +30，普通 +10，讨厌 -15。
- 生日 ×2；生日沿用 demo 数据，每季 1–28 日。
- 冬夜灯会（冬 5）送礼 ×3，和生日叠加时按好感上限 100 封顶。
- **野花**是 47/49 位居民都喜欢的通用礼物。
- 老板娘喜欢萝卜 / 土豆 / 萝卜种子 / 土豆种子。
- 老木匠喜欢木材 / 南瓜 / 南瓜种子 / 蘑菇。

### 冲好感的顺序

1. 老板娘 → 朋友：每天多收购 2 件作物，1.5 倍价。
2. 老木匠 → 朋友：建造材料 8 折。
3. 邻家女孩 → 朋友：送稀有种子。
4. 其他居民 → 朋友 / 挚友：成就、剧情、图鉴。

每天顺路送 5–10 人即可，不必 49 人全送。

## 7. 收集包

建社区中心：

```text
木材 ×50 + 石头 ×50 + 1000 金
```

建好后进去按 `E` 打开面板，逐件交付，集满自动领金币。

优先级：

| 收集包 | 奖励 | 建议 |
|---|---:|---|
| 春季作物 | 800 | 青豆 10 天 / 花椰菜 12 天，第 1–3 天就种 |
| 夏季作物 | 830 | 番茄 / 辣椒 / 蓝莓 / 甜瓜 |
| 秋季作物 | 860 | 玉米要夏天种 |
| 高品质作物 | 890 | 需要金星作物，注意浇水和土壤肥力 |
| 动物 | 920 | 先养鸡和牛 |
| 工匠 | 950 | 加工台出来后顺带做 |
| 建筑 | 1200 | 木材 / 石头需求大，提前攒 |
| 鱼类 | 1360–1510 | 钓鱼时顺手留 |
| 地质学家 | 1770 | 下矿时留宝石 |

作物类收集包最容易卡时间，优先处理。

## 9. 矿井

- `J` 进出，`WASD` 移动，空格攻击。
- 山地矿井入口按 `E` 也可以下矿；到达 B5 后，入口会变成电梯，可从已解锁的 5 层倍数直接开始。
- 最深纪录随存档保存，新游戏重置为 B1。
- 每 5 层首次到达有矿工宝箱：金币 + 宝石（B10 紫水晶、B15 黄玉、B20 红宝石、B30 钻石），领取记录随存档保存。
- 分层主题：B1–B39 岩石层、B40–B79 冰霜层、B80+ 熔岩层。冰霜层多出冰泪 / 石英，熔岩层多出火石英 / 地晶，配色也会同步变化。
- 生命 100，每下一层回 12。
- 越深怪物越强，矿石越好。
- 前期目标：铜矿、铁矿、煤炭、石英。
- 中期目标：金矿、红宝石、钻石、装备。
- 不要在生命低于 30 时继续往下。
- 打不过就回农场，矿井进度不会丢。

## 11. 技能与职业

五项技能都会随着对应操作涨经验：

| 技能 | 经验来源 | 每级被动 |
|---|---|---|

### 工具升级与蓄力

- 拿着锄头 / 水壶 / 斧头 / 镐，到铁匠铺的铁砧旁按 `E` 升级。
- 费用：铜级 2000g + 铜矿 ×10；钢级 5000g + 铁矿 ×10；金级 10000g + 金矿 ×10。
- 水壶升级同时增加 10 点容量。
- 升级后按住左键约 0.6 秒，会按工具等级蓄力范围使用：
  - 铜级：1×3
  - 钢级：3×3
  - 金级：5×5
- 范围使用逐格扣体力，体力不够会自动停下；有作物的格子不会被范围工具误收。

## 12. 常见坑

1. **换季前没熟**：普通作物只活自己的季节，长周期作物要算好天数。
2. **冬天乱种**：冬天只有霜瓜和冬根能种。
3. **水壶没水**：右键在水边补满，别到地里才发现。
4. **背包满**：收获、钓鱼、捡矿都会被卡，出门前留 3–5 格。
5. **体力见底还下矿**：昏睡会扣次日上限。
6. **商店关门**：10:00–19:00，午休 12:00–13:00。
7. **找不到 NPC**：先看时间，店主和部分居民在室内。
8. **生日错过**：生日按 demo 的每季 1–28 日，出门前看日历 / 对话。
9. **只卖原料**：加工成工匠品通常多赚 50%–200%。
10. **不存档**：大改农田、下矿、刷成就前先保存。
