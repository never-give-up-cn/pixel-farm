# 像素农场 · 攻略手册

> 面向已经会操作、想把日子过得更有效率的玩家。
> 第一次玩先看 [游玩指南](游玩指南.md)。

## 1. 核心循环

每天优先做这四件事：

```text
浇水 / 收获 → 镇上卖货 + 送礼 → 采集 / 钓鱼 / 下矿 → 睡觉
```

三条硬约束：

1. **体力 250**，浇水、开垦、砍树、挖矿、奔跑都吃体力。
2. **一季只有 10 天**，作物必须卡在换季前成熟。
3. **商店 10:00–19:00**，老板娘 12:00–13:00 午休。

## 2. 第一季（春 1–10 天）路线

### 第 1 天

- 在农舍附近开 20–30 块地。
- 先种防风草、土豆、胡萝卜，回本快。
- 想完成春季收集包，必须早点种：
  - 青豆 6 天成熟
  - 花椰菜 8 天成熟
  - 土豆 6 天成熟
  - 防风草 4 天成熟
- 下午去镇上对话、送礼，认识店主。
- 采集野花，留 5–10 朵当通用礼物。
- 睡前把水壶补满。

### 第 2–4 天

- 每天先浇水，再收获成熟作物。
- 防风草第 4 天开始收，土豆第 6 天收。
- 卖一部分作物，补种子；留一部分交收集包。
- 砍树攒木材，敲石头攒石材，为洒水器和鸡舍做准备。

### 第 5 天：播种祭

- 当天播种的作物生长速度 ×2。
- 把想种的作物留到这天播，尤其是花椰菜、青豆这类长周期作物。
- 注意：节日只加速当天播种的作物。

### 第 6–9 天

- 继续浇水、收获。
- 有余力造洒水器，减少每天的浇水体力。
- 开始攒鸡舍材料：木材 ×12。
- 每天给重点 NPC 送礼，优先冲「朋友」档。

### 第 10 天

- 收完所有当季作物。
- 没熟的作物会在换季时枯萎。
- 准备夏季种子：夏南瓜、辣椒、啤酒花、甜瓜。

## 4. 体力规划

250 体力大约能支持：

| 一天的内容 | 消耗 |
|---|---:|
| 50 块地浇水 | 50 |
| 50 块地开垦 | 150 |
| 50 次收获 | 50 |
| **合计** | **250** |

也就是说，**第一天开 50 块地 + 浇水 + 收获刚好见底**，没有余力下矿。

更稳的日常：

| 内容 | 消耗 |
|---|---:|
| 30 块地浇水 | 30 |
| 30 次收获 | 30 |
| 少量开垦 / 砍树 | 30–60 |
| 奔跑 30 秒 | 30 |
| **剩余** | **100+** |

建议：

- 农田控制在「浇水 + 收获 + 开垦」不超过 180。
- 造洒水器后，浇水体力直接归零。
- 随身带 2–3 份料理，每份 +40。
- 不要在体力低于 50 时下矿或远行。
- 2:00 前回家睡觉，昏睡会让次日上限变 200。

## 5. 赚钱路线

### 路线 A：作物 + 加工（最稳）

1. 春季青豆 / 土豆起手。
2. 夏季啤酒花 / 夏南瓜 / 辣椒。
3. 秋季葡萄 / 茄子。
4. 造加工台，把原料变成工匠品。

高价值配方（原料 → 成品）：

| 配方 | 原料 | 售价 |
|---|---|---:|
| 淡啤酒 | 啤酒花 ×3 | **547** |
| 葡萄酒 | 葡萄 ×3 | **518** |
| 咖啡 | 咖啡豆 ×3 | **480** |
| 松露油 | 松露 ×1 | **1100** |
| 布 | 羊毛 ×1 | **700** |
| 果汁 | 番茄 ×3 | 250 |
| 腌菜 | 土豆 ×3 | 288 |
| 奶酪 | 牛奶 ×2 | 200 |
| 蛋黄酱 | 鸡蛋 ×1 | 190 |

优先把「单价高、产量大」的原料送进加工台，不要直接卖。

### 路线 B：动物

| 动物 | 价格 | 成熟 | 产物 | 加工后 |
|---|---:|---:|---|---:|
| 鸡 | 120 | 2 天 | 鸡蛋 | 蛋黄酱 190 |
| 牛 | 260 | 4 天 | 牛奶 | 奶酪 200 |
| 鸭 | 200 | 4 天 | 鸭蛋 | 鸭蛋黄酱 220 |
| 羊 | 800 | 3 天 | 羊毛 | 布 700 |
| 猪 | 1600 | 5 天 | 松露 | 松露油 1100 |
| 兔 | 400 | 6 天 | 兔脚 | — |

- 每天喂饲料（8 金）+ 摸头，好感才涨。
- 好感 50 以上稳定产出，越高越容易出优质产品。
- 鸡和牛回本最快；猪最贵但松露油最赚。

### 路线 C：钓鱼

- 鱼竿开局就有，0 成本。
- 稀有鱼绿区小，但单价高。
- 雨天 / 特定时段会出稀有鱼。
- 鱼可以交河鱼 / 湖鱼 / 海鱼 / 夜间鱼收集包。
- 钓到重复鱼就卖，第一條留图鉴。

### 路线 D：下矿

- 矿石、宝石、煤炭都能卖。
- 怪物掉装备，装备也能卖。
- 深层收益高，但需要武器和料理。
- 前期只下 5–10 层，攒铜矿 / 铁矿 / 煤炭就回。

| 9:00–14:00 | 特殊访客在镇上 |

| 14:00–22:00 | 邻家女孩在自家花摊 |

| 21:00 后 | 普通村民回家 |
| 22:00 后 | 特殊访客离开 |

### 送礼

- 每人每天 1 次。
- 喜欢 +30，普通 +10，讨厌 -15。
- 生日 ×2。
- 冬夜灯会（冬 5）送礼 ×3，和生日叠加时按上限 100 封顶。
- **野花**是 47/49 位居民都喜欢的通用礼物。
- 老板娘喜欢萝卜 / 土豆 / 萝卜种子 / 土豆种子。
- 老木匠喜欢木材 / 南瓜 / 南瓜种子 / 蘑菇。

### 冲好感的顺序

1. 老板娘 → 朋友：每天多收购 2 件作物，1.5 倍价。
2. 老木匠 → 朋友：建造材料 8 折。
3. 邻家女孩 → 朋友：送稀有种子。
4. 其他居民 → 朋友 / 挚友：成就、剧情、图鉴。

每天顺路送 5–10 人即可，不必 49 人全送。

## 7. 收集包

建社区中心：

```text
木材 ×50 + 石头 ×50 + 1000 金
```

建好后进去按 `E` 打开面板，逐件交付，集满自动领金币。

优先级：

| 收集包 | 奖励 | 建议 |
|---|---:|---|
| 春季作物 | 800 | 第 1 天就种青豆 / 花椰菜 |
| 夏季作物 | 830 | 番茄 / 辣椒 / 蓝莓 / 甜瓜 |
| 秋季作物 | 860 | 玉米要夏天种 |
| 高品质作物 | 890 | 需要金星作物，注意浇水和土壤肥力 |
| 动物 | 920 | 先养鸡和牛 |
| 工匠 | 950 | 加工台出来后顺带做 |
| 建筑 | 1200 | 木材 / 石头需求大，提前攒 |
| 鱼类 | 1360–1510 | 钓鱼时顺手留 |
| 地质学家 | 1770 | 下矿时留宝石 |

作物类收集包最容易卡时间，优先处理。

## 8. 成就路线

32 个成就里，最容易漏的：

| 成就 | 做法 |
|---|---|
| 日进斗金 | 同一天卖出 500 金以上 |
| 建设者 / 基建狂魔 / 建筑巨匠 | 累计建造 10 / 30 / 50 次，木栅栏最便宜 |
| 礼尚往来 | 累计送 10 份礼物 |
| 三人成友 | 3 位居民到「朋友」 |
| 人气王 | 好感总和 150 |
| 鱼类行家 / 大师 | 钓 25 / 50 种鱼 |
| 矿物收藏 / 学家 / 全鉴 | 收集 10 / 25 / 53 种矿物 |
| 十全十美 / 作物百科 | 收获 10 / 20 种作物 |
| 活过一整年 | 玩到第 41 天 |

建造类成就可以用便宜栅栏反复建造刷次数；拆除返还 50% 材料。

## 9. 矿井

- `J` 进出，`WASD` 移动，空格攻击。
- 生命 100，每下一层回 12。
- 越深怪物越强，矿石越好。
- 前期目标：铜矿、铁矿、煤炭、石英。
- 中期目标：金矿、红宝石、钻石、装备。
- 不要在生命低于 30 时继续往下。
- 打不过就回农场，矿井进度不会丢。

## 11. 常见坑

1. **换季前没熟**：普通作物只活自己的季节，长周期作物要算好天数。
2. **冬天乱种**：冬天只有霜瓜和冬根能种。
3. **水壶没水**：右键在水边补满，别到地里才发现。
4. **背包满**：收获、钓鱼、捡矿都会被卡，出门前留 3–5 格。
5. **体力见底还下矿**：昏睡会扣次日上限。
6. **商店关门**：10:00–19:00，午休 12:00–13:00。
7. **找不到 NPC**：先看时间，店主和部分居民在室内。
8. **生日错过**：游戏一季 10 天，生日已压缩到每季 1–10 日，出门前看日历 / 对话。
9. **只卖原料**：加工成工匠品通常多赚 50%–200%。
10. **不存档**：大改农田、下矿、刷成就前先保存。
