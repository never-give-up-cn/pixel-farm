# 像素农场 · 游玩指南

> 面向第一次进游戏的玩家：怎么操作、一天怎么过、每个系统怎么用。
> 想少走弯路、快速赚钱，请看 [攻略手册](攻略手册.md)。

## 1. 开始游戏

```bash
node serve.js
# 打开 http://127.0.0.1:8123/index.html
```

不能直接双击 `index.html`，浏览器会拦截 ES Modules。

进入页面后：

- **继续游戏**：读取当前存档槽。
- **新游戏**：清空当前槽，从第 1 天开始。
- 系统菜单里可以切换 3 个存档槽。

## 2. 开局自带

| 项目 | 数量 |
|---|---:|
| 金币 | 100 |
| 体力 | 250 / 250 |
| 水壶容量 | 20 |
| 工具 | 锄头 / 水壶 / 斧头 / 镐 / 镰刀 / 鱼竿 |
| 武器 | 生锈小剑 |
| 种子 | 防风草 ×10、土豆 ×5、花椰菜 ×3、郁金香 ×3 |

快捷栏 8 格，背包共 24 格。工具、种子、食物都要先选中才能用。

## 3. 操作

| 按键 / 鼠标 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动 |
| `Shift` + 移动 | 奔跑（1 体力 / 秒） |
| `E` | 交互：对话、进出门、睡觉、商店柜台、采集、开箱、加工台、动物 |
| 鼠标左键 | 使用手持物品 / 工具；按住可连续使用；钓鱼抛竿、拉杆 |
| 鼠标右键 | 水壶补水；手持食物时吃一份；钓鱼收竿 |
| `1` ~ `8` | 选择快捷栏 |
| `Tab` / `I` | 背包 |
| `B` | 建造模式 |
| `G` | 农场评级 / 雇工 |
| `H` | 装修模式（手持家具时） |
| `J` | 进入 / 离开矿井 |
| `Esc` | 关闭面板；没有面板时打开系统菜单 |
| `P` | 暂停 |
| `M` | 静音 / 取消静音 |
| 点击左上日期 | 日历 |
| 点击右上小地图 | 全屏地图 |

### 动作过渡

使用工具、播种、收获、吃东西、补水、采集、抛竿时，农夫会先播放对应动作：

- 动作播到命中帧，操作才真正结算。
- 动作期间人物站定，不能移动，也不能重复操作。
- 按住左键时，会在当前动作播完后自动接下一次。
- 吃东西、补水、抛竿同样要等动画走完才生效。

## 4. 界面

- **左上**：金币、日期、季节、时间、天气、明日预报。
- **体力条**：低于 50 会变红闪烁。体力归零后无法使用工具，只能吃东西或回床睡觉。
- **底部**：快捷栏。数字键切换，背包里可以拖动整理。
- **右上**：农场评级、小地图。
- **系统菜单**：保存 / 读取 / 删除、成就墙、居民好感、玩法速查、游戏状态、音量、画面开关、导入 / 导出。

## 5. 时间与季节

| 项目 | 规则 |
|---|---|
| 一天 | 6:00 起床，次日 2:00 强制昏睡 |
| 现实时长 | 一天约 6 分钟 |
| 一季 | 28 天 |
| 一年 | 4 季 × 28 天 = 112 天 |
| 睡觉 | 农舍床边按 `E`，回满体力 |
| 昏睡 | 2:00 还没睡，次日体力上限降到 200 |

季节变化时：

- 只能种当季作物。
- 换季后，不属于新季节的作物会枯萎。
- 多季作物（玉米、咖啡豆、上古水果、仙人掌果等）会跨季继续生长。
- 冬季只能种 **霜瓜** 和 **冬根**。

## 6. 体力

| 动作 | 消耗 |
|---|---:|
| 锄地 | 3 |
| 浇水 | 1 |
| 砍树 | 4 |
| 敲石头 | 4 |
| 割草 / 清理 | 2 |
| 收获 | 1 |
| 奔跑 | 1 / 秒 |
| 钓鱼失败 | 少量体力 |

- 吃一份料理恢复 **40** 体力。手持食物右键即可吃。
- 体力不足时工具不会生效，也不会扣体力。
- 睡觉回满；昏睡会扣上限。
- 洒水器可以大幅减少每天的浇水体力。

## 7. 种田

1. 选中锄头，左键点草地 / 泥地 → 开垦。
2. 选中种子，左键点耕地 → 播种。
3. 每天浇水一次。
4. 成熟后左键收获。
5. 换季前收完，否则非当季作物会枯萎。

要点：

- 只浇过水的作物才会在过夜时生长。
- 雨天会自动浇一次水。
- 作物品质由 **浇水完整度、当季、节日、土壤肥力** 决定；优质作物售价约为普通 1.8 倍。
- 收获会消耗土壤肥力；旁边种不同作物可以轮作恢复。
- 相邻种两种不同作物，有小概率杂交出稀有种子。
- 水壶容量 20，可在商店升级两次：20 → 30 → 40。
- 水壶空了到水边右键补水。

## 8. 商店与出售

- 杂货店在镇上，进店走到柜台按 `E`。
- 营业时间约 **10:00–19:00**；老板娘 12:00–13:00 会出去午休。
- 买：种子、饲料、动物、家具、墙纸、地板、水壶升级等。
- 卖：作物、鱼、矿物、采集物、动物产品、料理、装备、家具等。
- 价格每天有小幅波动，秋季整体略高、冬季略低。
- 老板娘成为朋友后，每天会额外加购 2 件作物，价格 1.5 倍。

## 9. 小镇与 NPC

镇上有 **49 位 NPC**：34 位村民、12 位特殊访客、3 位店主。

- 走近按 `E` 对话。
- 对话面板里点「送礼」，每天每人只能送一次。
- 喜欢的东西 +30，普通 +10，讨厌 -15。
- 生日当天送礼好感 ×2。生日沿用 demo 数据，每季 1–28 日。
- 好感档位：陌生 0 / 熟悉 25 / 朋友 60 / 挚友 85。
- 成为朋友会解锁福利：
  - 老板娘：每天加购作物。
  - 老木匠：建造材料 8 折。
  - 邻家女孩：送稀有种子。

作息：

- 普通村民 8:00 上街，12:00 广场，13:00 回街上，18:00 广场，21:00 回家。
- 特殊访客 9:00–22:00 在镇上。
- 老板娘 10:00–19:00 在店里。
- 老木匠 14:00–18:00 在街上。
- 邻家女孩 9:00–13:00 在街上，14:00–22:00 在自家花摊。

找不到人时，先看时间；店主和部分居民在室内，需要进店 / 进屋。

## 10. 钓鱼

1. 快捷栏选中鱼竿。
2. 站到水边，左键抛竿。
3. 等 1–4 秒，出现咬钩提示后左键。
4. 拉杆时指针会来回移动，在绿区内左键收鱼。

鱼越稀有，绿区越小。全游戏共 77 种鱼，按季节、时段、天气出现。

## 11. 采集

- 草地上会刷新季节采集物。
- 走近按 `E` 采集，会进背包并解锁图鉴。
- 野花是大多数居民都喜欢的万用礼物。

## 12. 矿井与战斗

- 按 `J` 进入矿井，`Esc` 退出。
- `WASD` 移动，空格挥剑。
- 打碎矿石、击杀怪物，走到梯子下一层。
- 每下一层回复 12 点生命。
- 矿井越深，怪物越强，矿石和装备掉落越好。
- 矿里有 53 种矿物和 110 件装备可收集。

## 13. 建造

按 `B` 进入建造模式：

- 滚轮切换配方。
- 左键放置，右键拆除。
- 拆除返还 50% 材料。
- 建造范围 5 格。
- 石板路会提高移动速度。

前期推荐：

| 建筑 | 材料 | 用途 |
|---|---|---|
| 木箱 | 木材 ×8 | 储物 |
| 洒水器 | 石头 ×5 + 木材 ×5 | 自动浇 3×3 |
| 鸡舍 | 木材 ×12 | 养鸡 / 鸭 / 兔 |
| 牛棚 | 木材 ×20 + 石头 ×6 | 养牛 / 羊 / 猪 |
| 加工台 | 木材 ×10 + 石头 ×5 | 工匠品 / 料理 |
| 灶台 | 木材 ×15 + 石头 ×10 | 烹饪 |
| 社区中心 | 木材 ×50 + 石头 ×50 + 1000 金 | 收集包 |
| 温室 | 木材 ×30 + 石头 ×20 + 800 金 | 高级种植 |
| 黄金时钟 | 石头 ×50 + 5000 金 | 终局建筑 |

## 14. 农舍室内

走到农舍门口按 `E` 进入：

- `WASD` 走动。
- 床边按 `E` 睡觉。
- 灶台旁按 `E` 烹饪。
- 按 `H` 进入室内装修：左键摆家具，右键收回。
- 走到门口按 `E` / `Esc` 离开。

建造「装修样板」后，可以应用 32 种墙纸和 24 种地板。建造「衣柜」后可以换 90 顶帽子 / 64 件上衣 / 16 件下装。

## 15. 动物与宠物

养动物前先建鸡舍或牛棚，然后在商店购买：

| 动物 | 价格 | 住所 | 产品 |
|---|---:|---|---|
| 鸡 | 120 | 鸡舍 | 鸡蛋 |
| 鸭 | 200 | 鸡舍 | 鸭蛋 |
| 兔 | 400 | 鸡舍 | 兔脚 |
| 牛 | 260 | 牛棚 | 牛奶 |
| 羊 | 800 | 牛棚 | 羊毛 |
| 猪 | 1600 | 牛棚 | 松露 |

- 每天喂饲料，好感 +5；摸头 +2；饿着 -5。
- 好感达到 50 才会稳定产出。
- 好感越高，优质产品概率越高（10%–45%）。

宠物有 15 种，在农舍附近走动。按 `E` 抚摸；宠物碗可以切换品种。

## 16. 收集

| 系统 | 内容 |
|---|---|
| 图鉴 | 348 条：77 鱼 / 53 矿物 / 50 作物 / 6 动物 / 49 怪物 / 110 装备 / 3 采集物 |
| 收集包 | 30 个，建社区中心后交付，每个都有金币奖励 |
| 成就 | 32 个，按种植 / 经济 / 社交 / 探索分类 |

图鉴在首次收获、钓鱼、拾取、击杀、购买动物时自动解锁。

## 17. 烹饪与工匠品

- 建造灶台或加工台后，按 `E` 打开面板。
- 选择配方，材料够就能开始。
- 加工按游戏时间推进，睡觉也会继续。
- 成品放进产出槽，记得取走。
- 料理吃一份恢复 40 体力，也可以卖钱。
- 工匠品包括葡萄酒、果汁、腌菜、奶酪、蛋黄酱、布、松露油等，通常比原料贵很多。

## 18. 存档

- 系统菜单 → 保存游戏 / 读取存档 / 删除存档。
- 共 3 个存档槽。
- 存档在浏览器 `localStorage`，换浏览器或清缓存会丢。
- 支持导出 / 导入存档文本。

## 19. 常见问题

**打开是黑屏 / 报错？**
用 `node serve.js` 起服务，不要直接双击 HTML。

**商店没人？**
老板娘 10:00–19:00 在柜台，12:00–13:00 午休。

**作物不长大？**
当天没浇水，或者不是当季作物。

**换季后作物枯了？**
普通作物只活自己的季节。多种多季作物，或换季前收完。

**体力不够？**
先升级水壶、造洒水器，再考虑扩大农田；随身带料理。

**NPC 找不到？**
看时间。普通村民 8:00 后才上街；店主在室内；22:00 后基本都回家了。

**冬天能种什么？**
霜瓜和冬根。其他种子冬天不能播种。

**怎么赚钱快？**
看 [攻略手册](攻略手册.md) 的作物收益和加工路线。
