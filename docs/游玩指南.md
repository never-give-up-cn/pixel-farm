# 像素农场 · 游玩指南

> 面向第一次进游戏的玩家：怎么操作、一天怎么过、每个系统怎么用。
> 想少走弯路、快速赚钱，请看 [攻略手册](攻略手册.md)。

## 1. 开始游戏

```bash
node serve.js
# 打开 http://127.0.0.1:8123/index.html
```

不能直接双击 `index.html`，浏览器会拦截 ES Modules。

进入页面后：

- **读取存档**：打开本地全部存档列表（数量不限），每条存档可以读取或删除。
- **新游戏**：选择 **标准 / 河流 / 森林 / 山顶** 四种农场之一，然后创建一个新存档；**不会覆盖旧存档**。开局出生在独立的**农场**地图，往南走到主路尽头进入鹈鹕镇。
- 存档摘要会显示天数、季节、天气、农场类型、金币、体力和保存时间。
- 游戏内想切换其他存档：暂停菜单 → 返回标题 → 读取存档。

### 动作过渡

使用工具、播种、收获、吃东西、补水、采集、抛竿时，农夫会先播放对应动作：

- 动作播到命中帧，操作才真正结算。
- 动作期间人物站定，不能移动，也不能重复操作。
- 按住左键时，会在当前动作播完后自动接下一次。
- 吃东西、补水、抛竿同样要等动画走完才生效。

### 自动进出建筑 / 切地图

- 城镇住宅和商店：直接走过门口那格门，像正常走路一样进出，不会瞬移。
- 农舍：走到屋前门口自动进入；在室内走到最里面的门口自动回到农场。
- 独立地图住宅（罗宾家 / 玛妮牧场 / 莉亚小屋 / 法师塔 / 鱼店 / 公会等）：走到地标门口自动进入，室内走到门口自动回外景。
- 地图出口：走到地图边缘的出口格会自动切到下一张地图，不需要按 `E`。
- 门格和地图出口都只触发一次；进入后会先站稳，避免按住方向键时又立刻走回去。

## 4. 界面

- **左上**：金币、日期、季节、时间、天气、明日预报。
- **体力条**：低于 50 会变红闪烁。体力归零后无法使用工具，只能吃东西或回床睡觉。
- **底部**：快捷栏。数字键切换，背包里可以拖动整理。
- **右上**：农场评级、小地图。
- **系统菜单**：保存 / 读取 / 删除、成就墙、居民好感、玩法速查、游戏状态、音量、画面开关、导入 / 导出。

## 5. 时间与季节

| 项目 | 规则 |
|---|---|
| 一天 | 6:00 起床，次日 2:00 强制昏睡 |
| 现实时长 | 一天约 6 分钟 |
| 一季 | 28 天 |
| 一年 | 4 季 × 28 天 = 112 天 |
| 睡觉 | 农舍床边按 `E`，回满体力；入睡后弹出当日总结，确认后进入第二天 |
| 昏睡 | 2:00 还没睡，次日体力上限降到 200 |

睡前的当日总结会列出：今日收入、金币变化、收获 / 钓鱼数量、送礼次数、新成就、农场评级和体力恢复情况。点「确认，开始新的一天」或按 `Enter` 才会真正翻页并自动存档，避免手滑睡过一天。

季节变化时：

- 只能种当季作物。
- 换季后，不属于新季节的作物会枯萎。
- 多季作物（玉米、咖啡豆、上古水果、仙人掌果等）会跨季继续生长。
- 冬季只能种 **霜瓜** 和 **冬根**。

## 6. 体力

| 动作 | 消耗 |
|---|---:|
| 锄地 | 3 |
| 浇水 | 1 |
| 砍树 | 4 |
| 敲石头 | 4 |
| 割草 / 清理 | 2 |
| 收获 | 1 |
| 奔跑 | 1 / 秒 |
| 钓鱼失败 | 少量体力 |

- 吃一份料理恢复 **40** 体力。手持食物右键即可吃。
- 体力不足时工具不会生效，也不会扣体力。
- 睡觉回满；昏睡会扣上限。
- 洒水器可以大幅减少每天的浇水体力。

## 7. 种田

1. 选中锄头，左键点草地 / 泥地 → 开垦。
2. 选中种子，左键点耕地 → 播种。
3. 每天浇水一次。
4. 成熟后左键收获。
5. 换季前收完，否则非当季作物会枯萎。

要点：

- 只浇过水的作物才会在过夜时生长。
- 雨天会自动浇一次水。
- 作物品质由 **浇水完整度、当季、节日、土壤肥力** 决定；优质作物售价约为普通 1.8 倍。
- 收获会消耗土壤肥力；旁边种不同作物可以轮作恢复。
- 相邻种两种不同作物，有小概率杂交出稀有种子。
- 水壶容量 20，可在商店升级两次：20 → 30 → 40。
- 水壶空了到水边右键补水。

## 8. 商店与出售

- 杂货店在镇上，进店走到柜台按 `E`。
- 营业时间约 **10:00–19:00**；老板娘 12:00–13:00 会出去午休。
- 买：种子、饲料、动物、家具、墙纸、地板、水壶升级等。
- 卖：作物、鱼、矿物、采集物、动物产品、料理、装备、家具等。
- 价格每天有小幅波动，秋季整体略高、冬季略低。
- 老板娘成为朋友后，每天会额外加购 2 件作物，价格 1.5 倍。

### 旅行货车

煤渣森林里有一辆 **旅行货车**（东岸、桥北侧），走近按 `E` 打开。

- 每 **3 天** 换一批货，每次 4 件。
- 商品从矿物、矿石、种子、料理、饲料、木材中随机抽取。
- 价格比普通商店贵 **30%**，面板里会直接标「货车价 ×1.3」。
- 只买不卖；补货日会在标题下方显示。
- 适合补齐当天商店买不到的材料，或者碰碰运气买稀有种子 / 矿石。

## 9. 小镇与 NPC

镇上有 **49 位 NPC**：34 位村民、12 位特殊访客、3 位店主；分布在 **29 栋住宅** 里，有些家庭合住。

- 农场和小镇现在是**两张独立地图**：从农场南边主路一直往下走，会切到小镇北入口；小镇北边主路走回去就是农场。
- 住宅区分四排，每排 8 个地块；南北主路贯穿四排。
- 点击右上小地图打开全屏地图：上方可以切换**所有地图场景**，下方列出**所有 49 位 NPC 当前所在的地图 / 状态**；地图上的色点就是 NPC。
- 全屏地图只会切换查看，不会把你传送过去；按 `Esc` 或再点小地图关闭。
- 对话框标题会显示居民的职业。
- 门口牌子会写「谁在家 / 正在工作 / 主人出去了」。
- 住宅门可以直接走进去 / 走出来：门格是普通可走格，穿过门会自然走进室内地板，不会瞬移。
- 走进住宅可以找到在家的居民；工作地点在室内的居民需要进对应店铺 / 住宅。

- 走近按 `E` 对话。
- 对话面板里点「送礼」，每天每人只能送一次。
- 喜欢的东西 +30，普通 +10，讨厌 -15。
- 生日当天送礼好感 ×2。生日沿用 demo 数据，每季 1–28 日。
- 好感档位：陌生 0 / 熟悉 25 / 朋友 60 / 挚友 85。
- 成为朋友会解锁福利：
  - 老板娘：每天加购作物。
  - 老木匠：建造材料 8 折。
  - 邻家女孩：送稀有种子。

作息：

- 6:00–8:00 多数人在家；8:00–9:00 上班族和学生陆续上街。
- 9:00–17:00 各自在工作地点：店铺柜台、工作台、书桌、博物馆等。
- 17:00–21:00 下班居民在住宅附近的街上，镇子最热闹。
- 老板娘 10:00–19:00 在杂货店柜台，12:00–13:00 午休。
- 邻家女孩 14:00–22:00 在自家花摊。
- 21:00 后普通居民回家；夜班（酒馆 / 赌场）会工作到 24:00。

找不到人时，先看时间，再看门口牌子；店主和部分居民在室内，需要进店 / 进屋。住宅、职业和工作地点见 [NPC 居住与工作](NPC居住与工作.md)。

小镇里的特色室内也可以逛：

- 博物馆：展柜、展品；手里拿着古物按 `E` 可以捐赠（每次 +120 金币，集齐 24 件奖励 5000 金币 + 钻石）
- Joja 超市：货箱、货架；按 `E` 打开完整 Joja 货架面板
- 星之果实酒馆：柜台、点唱机、酒桶；点唱机可以在 4 首曲子之间轮换播放
- 哈维诊所：病床、药柜、书桌；按 `E` 花 40 金币回满体力
- 铁匠铺：铁砧、工作台
- 鱼店：鱼缸、柜台、酒桶

靠近这些家具按 `E` 可以查看描述或使用功能。

### 周边地图

农场与小镇现在是两张地图，周围还有：

- **农场北边**：山地（湖泊、木匠店、矿井、冒险家公会、莱纳斯帐篷）；山地东北的采石场桥可以按 `E` 进入采石场采矿石。
- **小镇西边**：煤渣森林（河流、池塘、玛妮牧场、莉亚小屋、法师塔、旅行货车）。
- **森林西北角**：秘密森林（大原木按 `E` 进入，六棵硬木树桩每天可砍，古老雕像可用甜宝石浆果换体力上限 +10）。
- **小镇南边**：鹈鹕海滩（沙滩、栈桥、鱼店、艾利欧特小屋）。
- **小镇东边**：巴士站（修好巴士后去沙漠）。

走到地图边缘的主路出口会自动切换，左上角日期栏会显示当前地图名。农场、煤渣森林、山地、海滩等户外地图可以用斧头 / 镐 / 镰刀砍树、敲石头、割草；开垦 / 播种 / 浇水仍限农场。部分居民白天会跨地图上班（罗宾一家在山地、玛妮 / 莉亚 / 法师在森林、威利 / 艾利欧特在海滩），17:00 左右回镇上。罗宾家、玛妮牧场、莉亚小屋、法师塔、威利鱼店、艾利欧特小屋、冒险家公会走到门口就会自动进入室内，室内走到门口自动回外景；床可睡觉、箱子可储物、灶台可烹饪。矿井入口按 `E` 直接下矿。详见 [多地图说明](地图说明.md)。

## 10. 钓鱼

1. 快捷栏选中鱼竿。
2. 站到水边，左键抛竿。
3. 等 1–4 秒，出现咬钩提示后左键。
4. 拉杆时指针会来回移动，在绿区内左键收鱼。

鱼越稀有，绿区越小。全游戏共 77 种鱼，按季节、时段、天气出现。

## 11. 采集

- 草地上会刷新季节采集物。
- 走近按 `E` 采集，会进背包并解锁图鉴。
- 野花是大多数居民都喜欢的万用礼物。

## 12. 矿井与战斗

- 按 `J` 进入矿井，`Esc` 退出。
- 走到山地矿井入口按 `E`：还没解锁电梯时直接下 B1；解锁后打开电梯面板选楼层。
- 每下 5 层解锁一个电梯直达层（B5 / B10 / B15……），最深层会随存档保存。
- 每 10 层首次到达会出现一个矿工宝箱（位置随机，可能藏在岩石堆里），走上去领取金币和宝石；领取过的宝箱不会重复出现。
- 矿井分三层主题：B1–B39 岩石层、B40–B79 冰霜层、B80 起熔岩层；背景、岩壁和矿石池都会变化，越深越容易出稀有矿。
- 矿层由岩石团和随深度变化的矿脉组成：浅层铜多，B10 后出铁，B25 后出金，煤炭全层都有。
- 下一层梯子藏在随机地板格：清光本层怪物，或敲岩石 / 矿石（有概率直接露出）后出现；矿层快挖空时保底出现。楼梯道具仍然可以直接下一层。
- 怪物数量随深度增加（3 → 8），有些楼层是**怪物层**：整层没有岩石 / 矿石，只有 8–11 只怪；清光全部怪物后梯子才会出现。
- 杂货店出售炸弹（300g）和楼梯（500g）：矿井里按 `Q` 引爆炸弹，清理周围岩石 / 矿石并炸伤怪物；按 `R` 消耗楼梯直接下一层。
- 最深到达 B40 后，矿井入口面板会出现「💀 骷髅洞穴」：怪物更强、掉落更好，从 B1 重新开始，没有电梯直达。
- `WASD` 移动，空格挥剑。
- 打碎矿石、击杀怪物，走到梯子下一层。
- 每下一层回复 12 点生命。
- 矿井越深，怪物越强，矿石和装备掉落越好。
- 矿里有 53 种矿物和 110 件装备可收集。

## 13. 建造

按 `B` 进入建造模式：

- 滚轮切换配方。
- 左键放置，右键拆除。
- 拆除返还 50% 材料。
- 建造范围 5 格。
- 石板路会提高移动速度。

**大型建筑占多格**：鸡舍、牛棚、温室这类建筑不是只占一个格子，而是按占地铺开，整块都能挡路、都能右键拆除：

| 建筑 | 占地 |
|---|---|
| 鸡舍 / 小屋 / 筒仓 / 水井 / 磨坊 / 祝尼魔屋 | 2×2 |
| 牛棚 / 棚屋 / 马厩 / 史莱姆屋 / 鱼塘 / 社区中心 | 3×2 |
| 温室 | 3×3 |
| 木栅栏 / 木箱 / 洒水器 / 加工设备 / 家具 | 1×1 |

- 鼠标指向左上角锚点（高亮框的左上格）放置，预览会把整块占地逐格标色：绿色可放、红色被占 / 被挡住。
- 只要占地里有一格在水、树、石头、耕地、作物或别的建筑上，整栋就放不下，材料不会扣。
- 拆除时右键占地里任意一格都可以，整栋一起拆并返还材料。
- 旧存档里的单格大建筑读档时会自动扩展成默认占地；如果周围被树 / 作物堵住，会保持 1×1，不会吞掉你的东西。
- 大建筑占用的格子不能再开垦 / 浇水 / 播种，先拆掉再用工具。

前期推荐：

| 建筑 | 材料 | 用途 |
|---|---|---|
| 木箱 | 木材 ×8 | 储物 |
| 洒水器 | 石头 ×5 + 木材 ×5 | 自动浇 3×3 |
| 鸡舍 | 木材 ×12 | 养鸡 / 鸭 / 兔 |
| 牛棚 | 木材 ×20 + 石头 ×6 | 养牛 / 羊 / 猪 |
| 加工台 | 木材 ×10 + 石头 ×5 | 工匠品 / 料理 |
| 灶台 | 木材 ×15 + 石头 ×10 | 烹饪 |
| 社区中心 | 木材 ×50 + 石头 ×50 + 1000 金 | 收集包 |
| 温室 | 木材 ×30 + 石头 ×20 + 800 金 | 高级种植 |
| 黄金时钟 | 石头 ×50 + 5000 金 | 终局建筑 |

## 14. 农舍室内

走到农舍门口会自动进入（按 `E` 也可以）：

- `WASD` 走动。
- 床边按 `E` 睡觉。
- 灶台旁按 `E` 烹饪。
- 按 `H` 进入室内装修：左键摆家具，右键收回。
- 走到室内最里面的门口会自动回到农场（`E` / `Esc` 也可以）。

建造「装修样板」后，可以应用 32 种墙纸和 24 种地板。建造「衣柜」后可以换 90 顶帽子 / 64 件上衣 / 16 件下装。

## 15. 动物与宠物

养动物前先建鸡舍或牛棚，然后在商店购买：

| 动物 | 价格 | 住所 | 产品 |
|---|---:|---|---|
| 鸡 | 120 | 鸡舍 | 鸡蛋 |
| 鸭 | 200 | 鸡舍 | 鸭蛋 |
| 兔 | 400 | 鸡舍 | 兔脚 |
| 牛 | 260 | 牛棚 | 牛奶 |
| 羊 | 800 | 牛棚 | 羊毛 |
| 猪 | 1600 | 牛棚 | 松露 |

- 每天喂饲料，好感 +5；摸头 +2；饿着 -5。

宠物有 15 种，在农舍附近走动。按 `E` 抚摸；宠物碗可以切换品种。

## 17. 烹饪与工匠品

## 18. 存档

- 标题界面点「读取存档」打开全部存档列表，可任意读取 / 删除；存档数量不限（实际受浏览器 localStorage 容量限制）。
- 「新游戏」只选择农场类型并创建新存档，不会覆盖旧存档。
- 游戏内系统菜单 → 保存游戏 / 读取存档 / 删除存档，作用于当前存档；想切换存档先回标题（暂停菜单 → 返回标题）。
- 存档在浏览器 `localStorage`，换浏览器或清缓存会丢。
- 支持导出 / 导入存档文本。

## 19. 常见问题

**打开是黑屏 / 报错？**
用 `node serve.js` 起服务，不要直接双击 HTML。

**商店没人？**
老板娘 10:00–19:00 在柜台，12:00–13:00 午休。

**作物不长大？**
当天没浇水，或者不是当季作物。

**换季后作物枯了？**
普通作物只活自己的季节。多种多季作物，或换季前收完。

**体力不够？**
先升级水壶、造洒水器，再考虑扩大农田；随身带料理。

**NPC 找不到？**
看时间。大多数居民 8:00 后才陆续上街；店主和部分居民在室内；22:00 后基本都回家了。

**冬天能种什么？**
霜瓜和冬根。其他种子冬天不能播种。

**怎么赚钱快？**
看 [攻略手册](攻略手册.md) 的作物收益和加工路线。

## 20. 技能与工具升级

- 升级后的工具按住左键约 0.6 秒可蓄力，按等级覆盖 1×3 / 3×3 / 5×5；水壶升级还会 +10 容量。
- 具体职业表和升级费用见 [攻略手册](攻略手册.md) 的「技能与职业」。

## 23. 肥料与料理增益

- 杂货店出售三种肥料：
  - 基础肥料（100g）：品质评分 +10%
  - 优质肥料（300g）：品质评分 +20%
  - 高级肥料（600g）：品质评分 +30%
- 手持肥料，对着已经种下的作物按左键施用；同一块地只能用一次，高级会覆盖低级。
- 吃带增益的料理会获得当天有效的临时效果：速度、攻击、防御、钓鱼、采矿、最大体力。
- 料理增益持续到当天结束，第二天 6:00 自动清除；吃另一道菜会替换当前增益。

## 24. 戒指与靴子

- 在背包里**右键**戒指或靴子即可装备；再右键另一件会替换。
- 最多装备 2 枚戒指 + 1 双靴子，按 `L` 查看当前装备和属性总和。
- 生效属性：攻击、防御、免疫、幸运、速度、钓鱼、采矿、最大体力。
- 卸下时装备会回到背包；背包满时无法卸下。
- 武器仍然只看 dmg / crit，戒指和靴子提供额外的攻防与辅助效果。

## 26. 巴士与卡利科沙漠

- 从小镇第一条街一路往东走，街尽头就是**巴士站**。

- 沙漠里有：
  - **沙漠商人**：按 `E` 打开商店，价格比普通商店高 20%，出售炸弹、楼梯、铱矿石、杨桃种子、甜宝石浆果种子、仙人掌果等。

## 27. 赌场与齐先生

- 小镇第一排住宅最东边有一栋**赌场**，屋里是齐先生、保镖和打手。

- 和齐先生说话，对话面板里会多一个「🎲 齐先生」按钮，点开是任务页：
  - **第一课 · 耐心**：交 20 石材 → 15 齐币 + 俱乐部卡
  - **第二课 · 眼光**：铜矿石 15 + 煤炭 10 → 30 齐币
  - **第三课 · 深入**：铁矿石 10 + 金矿石 5 → 50 齐币
  - **第四课 · 胆量**：累计下注 500 齐币 → 100 齐币 + 钻石 ×5
  - **无尽的试炼**：铱矿石 5 → 30 齐币（可重复）

  - **🎰 老虎机**：下注 10 / 50 / 100 齐币，三个相同符号中奖（樱桃 ×4、铃铛 ×8、柠檬 ×12、钻石 ×30、7 ×100、星 ×500）；恰好两个樱桃退回本金。

- 齐币只能靠任务和赌场获得，不能换回金币；打开赌场面板时世界冻结，Esc 关闭。
- 俱乐部卡、齐币、任务进度和累计下注都随存档保存。

## 30. 农场类型

开局确认「新游戏」时，先从四种农场里选一种。农场是**独立地图**，主耕地约 30×22 格；类型只影响农场空地内部的地形和植被密度，**农舍、出生点和南北主路永远保通**，不会出现开局被困住的情况。

| 类型 | 特点 | 适合 |
|---|---|---|
| 🌾 标准农场 | 大片平整草地 + 小水塘，可耕地最多；树石集中在农场边缘 | 第一次玩、想大面积种田 |
| 🌊 河流农场 | 一条河从农场东半部穿过，出生点高度有桥；可耕地少一些 | 想钓鱼 / 喜欢水景布局 |
| 🌳 森林农场 | 农场边缘树木更多，开局要先清树；野外树木和采集物也更多 | 木材流、采集流、工匠品 |
| ⛰️ 山顶农场 | 农场边缘散布矿石和一小片水塘，石材多、平地少 | 下矿 / 建造流、喜欢石头地形 |

- 农场类型在开局后**不能更改**；想换类型只能在新槽位重开。
- 农场边缘的树、山顶农场的石头都可以用斧头 / 镐清掉，清完就是正常耕地；煤渣森林的树也可以砍。
- 河流农场和山顶水塘里可以钓鱼；桥面是天然通道，不用担心过不去。
- 农场类型会写进存档，读档后地形与类型都会恢复；旧存档没有这个字段时按标准农场读取。
- 农场类型不影响小镇、矿井、沙漠等其它地图。
