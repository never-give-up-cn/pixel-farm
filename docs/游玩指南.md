# 像素农场 · 游玩指南

> 面向第一次进游戏的玩家：怎么操作、一天怎么过、每个系统怎么用。
> 想少走弯路、快速赚钱，请看 [攻略手册](攻略手册.md)。

## 1. 开始游戏

```bash
node serve.js
# 打开 http://127.0.0.1:8123/index.html
```

不能直接双击 `index.html`，浏览器会拦截 ES Modules。

进入页面后：

- **继续游戏**：读取当前存档槽。
- **新游戏**：清空当前槽，从第 1 天开始。
- 系统菜单里可以切换 3 个存档槽。

## 2. 开局自带

| 项目 | 数量 |
|---|---:|
| 金币 | 100 |
| 体力 | 250 / 250 |
| 水壶容量 | 20 |
| 工具 | 锄头 / 水壶 / 斧头 / 镐 / 镰刀 / 鱼竿 |
| 武器 | 生锈小剑 |
| 种子 | 防风草 ×10、土豆 ×5、花椰菜 ×3、郁金香 ×3 |

快捷栏 8 格，背包共 24 格。工具、种子、食物都要先选中才能用。

### 动作过渡

使用工具、播种、收获、吃东西、补水、采集、抛竿时，农夫会先播放对应动作：

- 动作播到命中帧，操作才真正结算。
- 动作期间人物站定，不能移动，也不能重复操作。
- 按住左键时，会在当前动作播完后自动接下一次。
- 吃东西、补水、抛竿同样要等动画走完才生效。

## 4. 界面

- **左上**：金币、日期、季节、时间、天气、明日预报。
- **体力条**：低于 50 会变红闪烁。体力归零后无法使用工具，只能吃东西或回床睡觉。
- **底部**：快捷栏。数字键切换，背包里可以拖动整理。
- **右上**：农场评级、小地图。
- **系统菜单**：保存 / 读取 / 删除、成就墙、居民好感、玩法速查、游戏状态、音量、画面开关、导入 / 导出。

## 5. 时间与季节

| 项目 | 规则 |
|---|---|
| 一天 | 6:00 起床，次日 2:00 强制昏睡 |
| 现实时长 | 一天约 6 分钟 |
| 一季 | 28 天 |
| 一年 | 4 季 × 28 天 = 112 天 |
| 睡觉 | 农舍床边按 `E`，回满体力 |
| 昏睡 | 2:00 还没睡，次日体力上限降到 200 |

季节变化时：

- 只能种当季作物。
- 换季后，不属于新季节的作物会枯萎。
- 多季作物（玉米、咖啡豆、上古水果、仙人掌果等）会跨季继续生长。
- 冬季只能种 **霜瓜** 和 **冬根**。

## 6. 体力

| 动作 | 消耗 |
|---|---:|
| 锄地 | 3 |
| 浇水 | 1 |
| 砍树 | 4 |
| 敲石头 | 4 |
| 割草 / 清理 | 2 |
| 收获 | 1 |
| 奔跑 | 1 / 秒 |
| 钓鱼失败 | 少量体力 |

- 吃一份料理恢复 **40** 体力。手持食物右键即可吃。
- 体力不足时工具不会生效，也不会扣体力。
- 睡觉回满；昏睡会扣上限。
- 洒水器可以大幅减少每天的浇水体力。

## 7. 种田

1. 选中锄头，左键点草地 / 泥地 → 开垦。
2. 选中种子，左键点耕地 → 播种。
3. 每天浇水一次。
4. 成熟后左键收获。
5. 换季前收完，否则非当季作物会枯萎。

要点：

- 只浇过水的作物才会在过夜时生长。
- 雨天会自动浇一次水。
- 作物品质由 **浇水完整度、当季、节日、土壤肥力** 决定；优质作物售价约为普通 1.8 倍。
- 收获会消耗土壤肥力；旁边种不同作物可以轮作恢复。
- 相邻种两种不同作物，有小概率杂交出稀有种子。
- 水壶容量 20，可在商店升级两次：20 → 30 → 40。
- 水壶空了到水边右键补水。

## 8. 商店与出售

- 杂货店在镇上，进店走到柜台按 `E`。
- 营业时间约 **10:00–19:00**；老板娘 12:00–13:00 会出去午休。
- 买：种子、饲料、动物、家具、墙纸、地板、水壶升级等。
- 卖：作物、鱼、矿物、采集物、动物产品、料理、装备、家具等。
- 价格每天有小幅波动，秋季整体略高、冬季略低。
- 老板娘成为朋友后，每天会额外加购 2 件作物，价格 1.5 倍。

### 旅行货车

煤渣森林里有一辆 **旅行货车**（东岸、桥北侧），走近按 `E` 打开。

- 每 **3 天** 换一批货，每次 4 件。
- 商品从矿物、矿石、种子、料理、饲料、木材中随机抽取。
- 价格比普通商店贵 **30%**，面板里会直接标「货车价 ×1.3」。
- 只买不卖；补货日会在标题下方显示。
- 适合补齐当天商店买不到的材料，或者碰碰运气买稀有种子 / 矿石。

## 9. 小镇与 NPC

镇上有 **49 位 NPC**：34 位村民、12 位特殊访客、3 位店主；分布在 **29 栋住宅** 里，有些家庭合住。

- 城镇在农场 **南边**，沿农场边缘的南北主路一直往下走即可进入。
- 住宅区分四排，每排 8 个地块；南北主路贯穿四排。
- 点击右上小地图打开全屏地图，可以看到四排住宅、街道和每栋门的位置。
- 对话框标题会显示居民的职业。
- 门口牌子会写「谁在家 / 正在工作 / 主人出去了」。
- 走进住宅可以找到在家的居民；工作地点在室内的居民需要进对应店铺 / 住宅。

- 走近按 `E` 对话。
- 对话面板里点「送礼」，每天每人只能送一次。
- 喜欢的东西 +30，普通 +10，讨厌 -15。
- 生日当天送礼好感 ×2。生日沿用 demo 数据，每季 1–28 日。
- 好感档位：陌生 0 / 熟悉 25 / 朋友 60 / 挚友 85。
- 成为朋友会解锁福利：
  - 老板娘：每天加购作物。
  - 老木匠：建造材料 8 折。
  - 邻家女孩：送稀有种子。

作息：

- 6:00–8:00 多数人在家；8:00–9:00 上班族和学生陆续上街。
- 9:00–17:00 各自在工作地点：店铺柜台、工作台、书桌、博物馆等。
- 17:00–21:00 下班居民在住宅附近的街上，镇子最热闹。
- 老板娘 10:00–19:00 在杂货店柜台，12:00–13:00 午休。
- 邻家女孩 14:00–22:00 在自家花摊。
- 21:00 后普通居民回家；夜班（酒馆 / 赌场）会工作到 24:00。

找不到人时，先看时间，再看门口牌子；店主和部分居民在室内，需要进店 / 进屋。住宅、职业和工作地点见 [NPC 居住与工作](NPC居住与工作.md)。

小镇里的特色室内也可以逛：

- 博物馆：展柜、展品；手里拿着古物按 `E` 可以捐赠（每次 +120 金币，集齐 24 件奖励 5000 金币 + 钻石）
- Joja 超市：货箱、货架；按 `E` 打开完整 Joja 货架面板
- 星之果实酒馆：柜台、点唱机、酒桶；点唱机可以在 4 首曲子之间轮换播放
- 哈维诊所：病床、药柜、书桌；按 `E` 花 40 金币回满体力
- 铁匠铺：铁砧、工作台
- 鱼店：鱼缸、柜台、酒桶

靠近这些家具按 `E` 可以查看描述或使用功能。

### 周边地图

农场与小镇不是唯一地图：

- **北边**：山地（湖泊、木匠店、矿井、冒险家公会、莱纳斯帐篷）；山地东北的采石场桥可以按 `E` 进入采石场采矿石。
- **西边**：煤渣森林（河流、池塘、玛妮牧场、莉亚小屋、法师塔、旅行货车）。
- **森林西北角**：秘密森林（大原木按 `E` 进入，六棵硬木树桩每天可砍，古老雕像可用甜宝石浆果换体力上限 +10）。
- **南边**：鹈鹕海滩（沙滩、栈桥、鱼店、艾利欧特小屋）。

走到地图边缘的主路出口会自动切换，左上角日期栏会显示当前地图名。新地图目前可以探索、钓鱼、看地标，但不能开垦或建造。部分居民白天会跨地图上班（罗宾一家在山地、玛妮 / 莉亚 / 法师在森林、威利 / 艾利欧特在海滩），17:00 左右回镇上。罗宾家、玛妮牧场、莉亚小屋、法师塔、威利鱼店、艾利欧特小屋、冒险家公会都可以按 `E` 进入室内，床可睡觉、箱子可储物、灶台可烹饪；矿井入口按 `E` 直接下矿。详见 [多地图说明](地图说明.md)。

## 10. 钓鱼

1. 快捷栏选中鱼竿。
2. 站到水边，左键抛竿。
3. 等 1–4 秒，出现咬钩提示后左键。
4. 拉杆时指针会来回移动，在绿区内左键收鱼。

鱼越稀有，绿区越小。全游戏共 77 种鱼，按季节、时段、天气出现。

## 11. 采集

- 草地上会刷新季节采集物。
- 走近按 `E` 采集，会进背包并解锁图鉴。
- 野花是大多数居民都喜欢的万用礼物。

## 12. 矿井与战斗

- 按 `J` 进入矿井，`Esc` 退出。
- 走到山地矿井入口按 `E`：还没解锁电梯时直接下 B1；解锁后打开电梯面板选楼层。
- 每下 5 层解锁一个电梯直达层（B5 / B10 / B15……），最深层会随存档保存。
- 每 5 层首次到达会出现一个矿工宝箱，走上去领取金币和宝石；领取过的宝箱不会重复出现。
- 矿井分三层主题：B1–B39 岩石层、B40–B79 冰霜层、B80 起熔岩层；背景、岩壁和矿石池都会变化，越深越容易出稀有矿。
- `WASD` 移动，空格挥剑。
- 打碎矿石、击杀怪物，走到梯子下一层。
- 每下一层回复 12 点生命。
- 矿井越深，怪物越强，矿石和装备掉落越好。
- 矿里有 53 种矿物和 110 件装备可收集。

## 13. 建造

按 `B` 进入建造模式：

- 滚轮切换配方。
- 左键放置，右键拆除。
- 拆除返还 50% 材料。
- 建造范围 5 格。
- 石板路会提高移动速度。

前期推荐：

| 建筑 | 材料 | 用途 |
|---|---|---|
| 木箱 | 木材 ×8 | 储物 |
| 洒水器 | 石头 ×5 + 木材 ×5 | 自动浇 3×3 |
| 鸡舍 | 木材 ×12 | 养鸡 / 鸭 / 兔 |
| 牛棚 | 木材 ×20 + 石头 ×6 | 养牛 / 羊 / 猪 |
| 加工台 | 木材 ×10 + 石头 ×5 | 工匠品 / 料理 |
| 灶台 | 木材 ×15 + 石头 ×10 | 烹饪 |
| 社区中心 | 木材 ×50 + 石头 ×50 + 1000 金 | 收集包 |
| 温室 | 木材 ×30 + 石头 ×20 + 800 金 | 高级种植 |
| 黄金时钟 | 石头 ×50 + 5000 金 | 终局建筑 |

## 14. 农舍室内

走到农舍门口按 `E` 进入：

- `WASD` 走动。
- 床边按 `E` 睡觉。
- 灶台旁按 `E` 烹饪。
- 按 `H` 进入室内装修：左键摆家具，右键收回。
- 走到门口按 `E` / `Esc` 离开。

建造「装修样板」后，可以应用 32 种墙纸和 24 种地板。建造「衣柜」后可以换 90 顶帽子 / 64 件上衣 / 16 件下装。

## 15. 动物与宠物

养动物前先建鸡舍或牛棚，然后在商店购买：

| 动物 | 价格 | 住所 | 产品 |
|---|---:|---|---|
| 鸡 | 120 | 鸡舍 | 鸡蛋 |
| 鸭 | 200 | 鸡舍 | 鸭蛋 |
| 兔 | 400 | 鸡舍 | 兔脚 |
| 牛 | 260 | 牛棚 | 牛奶 |
| 羊 | 800 | 牛棚 | 羊毛 |
| 猪 | 1600 | 牛棚 | 松露 |

- 每天喂饲料，好感 +5；摸头 +2；饿着 -5。
- 好感达到 50 才会稳定产出。
- 好感越高，优质产品概率越高（10%–45%）。

宠物有 15 种，在农舍附近走动。按 `E` 抚摸；宠物碗可以切换品种。

## 17. 烹饪与工匠品

- 建造灶台或加工台后，按 `E` 打开面板。
- 选择配方，材料够就能开始。
- 加工按游戏时间推进，睡觉也会继续。
- 成品放进产出槽，记得取走。
- 料理吃一份恢复 40 体力，也可以卖钱。
- 工匠品包括葡萄酒、果汁、腌菜、奶酪、蛋黄酱、布、松露油等，通常比原料贵很多。

## 18. 存档

- 系统菜单 → 保存游戏 / 读取存档 / 删除存档。
- 共 3 个存档槽。
- 存档在浏览器 `localStorage`，换浏览器或清缓存会丢。
- 支持导出 / 导入存档文本。

## 19. 常见问题

**打开是黑屏 / 报错？**
用 `node serve.js` 起服务，不要直接双击 HTML。

**商店没人？**
老板娘 10:00–19:00 在柜台，12:00–13:00 午休。

**作物不长大？**
当天没浇水，或者不是当季作物。

**换季后作物枯了？**
普通作物只活自己的季节。多种多季作物，或换季前收完。

**体力不够？**
先升级水壶、造洒水器，再考虑扩大农田；随身带料理。

**NPC 找不到？**
看时间。大多数居民 8:00 后才陆续上街；店主和部分居民在室内；22:00 后基本都回家了。

**冬天能种什么？**
霜瓜和冬根。其他种子冬天不能播种。

**怎么赚钱快？**
看 [攻略手册](攻略手册.md) 的作物收益和加工路线。

## 20. 技能与工具升级

- 按 `K` 打开技能面板，查看耕种 / 采集 / 钓鱼 / 采矿 / 战斗的等级、经验和职业。
- 收获作物、采集野物、砍树、钓鱼、采矿、击败怪物都会给对应技能加经验。
- 5 级和 10 级各选一个职业，职业会强化售价、掉落、钓鱼绿区或战斗数值。
- 拿着锄头 / 水壶 / 斧头 / 镐到铁匠铺铁砧旁按 `E` 升级（金币 + 铜 / 铁 / 金矿）。
- 升级后的工具按住左键约 0.6 秒可蓄力，按等级覆盖 1×3 / 3×3 / 5×5；水壶升级还会 +10 容量。
- 具体职业表和升级费用见 [攻略手册](攻略手册.md) 的「技能与职业」。

## 21. 恋爱与结婚

- 12 位可结婚角色（阿比盖尔、塞巴斯蒂安、佩妮等）在对话面板里会出现恋爱按钮。
- 好感达到 80 后，商店会出售 **花束**（800g）。带着花束和对方对话，点「送花束 · 开始交往」。
- 交往后好感达到 100，商店会出售 **美人鱼吊坠**（5000g）。带着吊坠对话，点「求婚」。
- 求婚 3 天后自动举行婚礼，配偶搬进农舍；在农舍里走到配偶身边按 `E` 可以聊天。
- 婚后每天可以亲吻一次，回复 20 点体力。
- 花束和吊坠不能当普通礼物送，只能在对话面板的恋爱按钮里使用。

## 22. 农场建筑功能

放置后走到建筑旁按 `E`：

| 建筑 | 功能 |
|---|---|
| 温室 | 周围 8 格内的作物无视季节、全年生长，并且每天自动浇水；冬天也能种 |
| 筒仓 | 每天早上自动喂所有动物，不用再逐个喂饲料 |
| 水井 | 按 `E` 直接把水壶补满，不用跑到河边 |
| 发货箱 | 把要卖的东西拿在手里按 `E`，整栈按商店价卖出（技能加成同样生效） |
| 鱼塘 | 手持鱼按 `E` 放入，3 天后再按 `E` 收鱼籽 ×2 |
| 磨坊 | 手持小麦 / 未碾米按 `E` 放入，1 天后再按 `E` 取面粉 / 大米 |

温室、筒仓、鱼塘、磨坊的状态都会随存档保存。

## 23. 肥料与料理增益

- 杂货店出售三种肥料：
  - 基础肥料（100g）：品质评分 +10%
  - 优质肥料（300g）：品质评分 +20%
  - 高级肥料（600g）：品质评分 +30%
- 手持肥料，对着已经种下的作物按左键施用；同一块地只能用一次，高级会覆盖低级。
- 吃带增益的料理会获得当天有效的临时效果：速度、攻击、防御、钓鱼、采矿、最大体力。
- 料理增益持续到当天结束，第二天 6:00 自动清除；吃另一道菜会替换当前增益。
